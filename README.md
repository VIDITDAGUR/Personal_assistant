# Personal_assistant
This is small assistant project which will do your task and it runs completely locally on your system without using cloud (majority of the features)
Data is also stored in your local system and it don't send any data to any big A.I companies 
I have divided this project into 2 parts one is which runs completely on your system and other which partially run on your system because the speech recognizing feature use Google API. And the model which runs locally is a bit slow and also depend on your system performance because the speech recognizing llm is locally installed.

the workflow is simple i have added enough comments in the code base so that anyone reading it could understand what's happening in particular line of code .
